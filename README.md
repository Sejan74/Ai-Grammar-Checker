# AI Grammar Checker App

## Project Overview
This project features a modern AI-powered grammar checking application with a glassmorphism UI, built using HTML, Tailwind CSS, and connected to an n8n automated backend workflow. The goal is to provide instant, tone-adjusted grammar corrections while keeping your voice intact.

## Tools & Tech Stack
- **Frontend:** HTML5, Tailwind CSS (Dark Glassmorphism Theme)
- **Backend Automation:** n8n Webhook Workflow
- **Hosting & Deployment:** Vercel
- **Mobile App Conversion:** Web2Apk / WebIntoApp (.apk)

## Key Features
- **Real-Time Analysis:** Instant text processing and grammar error correction.
- **Tone Customization:** Select from Clear & Natural, Professional, Academic, and Creative tones.
- **Responsive UI:** Fully optimized mobile and desktop experience.
